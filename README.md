# 💇‍♀️ Салон Красоты (1С:Предприятие 8.3 / EDT)

Учебный дипломный проект, разработанный в рамках курса «Разработчик 1С» от **Яндекс Практикума**. Проект представляет собой самописную конфигурацию 1С с интегрированными библиотеками БСП (Библиотека Стандартных Подсистем).

---

## 📌 О проекте

Конфигурация предназначена для автоматизации оперативного и бухгалтерского учета в салоне красоты. 

### Основные возможности:
* **Учет номенклатуры и услуг:** Разделение на товары и оказываемые услуги.
* **Закупки и поставки:** Оформление документа «Поступление товаров и услуг».
* **Учет затрат и взаиморасчетов:** Расчеты с контрагентами и отражение расходов компании.
* **Бухгалтерский учет:** Автоматическое проведение документов по регистрам (в т.ч. хозрасчетному регистру сведений/бухгалтерии).
